## 🛠️ Prerequisites

To run these scripts on your machine, you need:
* A modern web browser (Chrome, Firefox, Edge) to use the DevTools console.
* [Node.js](https://nodejs.org) installed if you prefer running scripts directly in your terminal.

---

## 🏃‍♂️ How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory:
   ```bash
   cd YOUR-REPOSITORY-NAME
   ```
3. Run any JavaScript file using Node.js:
   ```bash
   node path/to/filename.js
   ```
